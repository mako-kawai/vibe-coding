# mako's Learning

面向北大物理本科生日常使用的本地优先学习驾驶舱。首页聚合截止任务、今日课程、考试倒计时和学期状态，所有数据默认只保存在当前浏览器。

## 总入口

- 在线访问：[mako-kawai.github.io/vibe-coding](https://mako-kawai.github.io/vibe-coding/)
- 仓库入口：根目录 [`index.html`](./index.html)
- 本地预览：在仓库目录运行 `python -m http.server 4176`，打开 `http://127.0.0.1:4176/`

不要直接双击 HTML 文件使用完整功能。ES Modules、Service Worker 和 PWA 离线缓存需要通过 HTTP 提供页面。

## 工作区

- 总览：紧急任务、今日课程、考试倒计时、学期进度与六个工作区快捷入口
- 任务：统一管理作业与个人待办，支持精确截止、优先级、进度、标签、子任务、专注计时和已完成任务批量清理
- 课程：聚合课程任务、笔记、课表、正式成绩和原有资料页
- 笔记：Markdown、KaTeX、DOMPurify、推导模板、全文检索、本地附件及带课程元数据的 Markdown 导入导出
- 日程：手动录入、ICS 导入、UID 去重和每周重复，统一按 `Asia/Shanghai` 显示
- 成绩：百分制、等级制、P/NP 与特殊状态，支持 CSV 及北大教务页面复制文本导入，仅记录正式成绩并提供非官方 GPA 估算
- 设置：学期、头像、主题、可裁剪侧栏背景、背景透明度/饱和度/亮度、完整 ZIP 备份、合并/替换导入和恢复快照

## 数据与离线

结构化元数据存入版本化的 `AppStateV2`；笔记正文、附件和本地主题图片存入 IndexedDB。首次运行会幂等迁移旧课程、作业、待办、笔记和课表数据，旧键不会自动删除。

Marked、KaTeX、DOMPurify、Lucide、ical.js 和 JSZip 已固定版本放入 `vendor/`。Service Worker 预缓存核心页面、模块、原创背景和 KaTeX 字体，可在断网时继续查看、编辑和保存。

## 主题与版权

公开仓库只包含原创生成背景。枕社风格与柚子社风格主题只定义色板、标题框和装饰层；用户可在设置页导入自己有权使用的本地素材，文件不会上传或进入仓库。本项目与北京大学、枕社、柚子社均无隶属或授权关系。

## 测试

```bash
node --test
```

测试覆盖旧任务迁移与去重、截止状态、ICS UID 去重、CSV 与教务文本解析、笔记 Markdown 往返、图片裁剪边界、GPA 边界和静态离线依赖。发布前还应在 `1280x720`、`1440x900`、`390x844` 三档视口完成浏览器验收。
